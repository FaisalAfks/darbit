Studio round 8: the Recorder

The Recorder turns what you do into an action, a step-by-step macro saved in the open bot. You open it from the Library with Edit on (● Record). While recording, you can pause at any moment and add a check: wait for a picture, branch if it shows, or repeat until it's gone. The Studio steps aside while you play. Three ways to show the recorder while you play, then the editor you land in afterwards.

RAA pill at the top

Like the run pill: the time, the action's name, the steps so far, and Pause, Add check, Stop. Pausing drops the check menu down from the pill. It hides itself like the run pill when the mouse is away.

RBLive steps on the side

A narrow panel on the right lists each step as it's recorded: clicks with their target, keys, waits and checks. You see straight away what was caught, and can delete a wrong step without stopping. It covers part of the game, so it can be dragged to any edge, made smaller, or made see-through.

RCAlmost invisible

Only a small timer in a corner, and keys: Ctrl+Alt+P pause, Ctrl+Alt+C add a check, Ctrl+Alt+R stop. Clicks and keys flash briefly where they happen, so you know they were caught. Everything else waits for the editor. It's best for fast games, but you have to know the keys.

Afterwards: the action editor (in every option)

Stopping opens the action in the Studio, under Library › Actions. A timeline shows keys, mouse moves and checks. Below it is the step list, with breakpoints, and an inspector for the chosen step. The action is saved as plain Python in the bot (decision 0010), so it also opens in VS Code.
