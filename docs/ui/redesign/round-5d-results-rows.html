Studio round 5d: Results in rows, set up from code

No tile grids. The day starts with one plain sentence, a problem shows as a single line only when there is one, and gains and progress share one table. Each row shows today's number, the week as a small bar chart, and the total. The bot sets everything up from its code with d.record; there's nothing to configure.

The first one recorded leads the day list. d.record.gain("Gems", 120, total=48210, icon="◆") # adds to today, shows the last total d.record.gain("Gold", 500, total=212900, icon="●") d.record.gain("Chests", 1, note="rare") d.progress("Weekly characters", 92, 133) # already exists: a progress row d.record("speed raid done", character="Sakura") # plain events still work: the timeline and log

The sentence is built from the same numbers: run time, the first two gains, the share of rounds finished compared with usual, and time lost. Timeline lanes are the bot's top-level steps.

What changed from 5c

  • Set up from code: d.record.gain(...) and d.progress(...). There's no [studio.results] table.
  • No tiles: one sentence for the day, and one table for gains and progress (today, the week, total).
  • Day list: the date, the lead gain and how long it ran. A red dot marks a day with a problem.
  • Needs you: one line under the sentence, only when there's a problem. Totals merged into the table.
