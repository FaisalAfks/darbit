Studio round 4: the Library, and what Edit opens

The Library's goal is to manage everything the bot uses. It holds every asset type: images, regions, points, text, actions. You can rename an asset without breaking the bot, retake or fix one, and test one on screen. Edit (the purple button) unlocks adding and changing; without it, the Library is safe to browse. The three options differ in how the page is laid out.

AGrid and inspector

Like a photo app: thumbnails grouped by type on the left, and the selected asset in a panel on the right with everything you can do to it.

The same in every option

  • Without Edit: browse, search and Test on screen. Rename, Retake, Delete, Capture and Record are hidden, so nothing changes by accident.
  • Rename never breaks the bot: it shows every line it will change and changes them all at once, or none.
  • Test on screen is the old "Check", for one asset: the Studio steps aside, the asset glows where it's found, and its score shows.
  • Capture and Record open over the game and save into this bot's folder.
