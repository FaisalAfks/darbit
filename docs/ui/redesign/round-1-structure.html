AOne sidebar

Like Windows Settings or Discord: a single menu on the left, split in two labelled groups. Bots on top (the open bot shows its four pages under it), tools below.

  • Everything is in one place. It's always clear where you are.
  • A running bot's dot is always visible.
  • The sidebar takes 210 px. It can fold to icons.

BHome, then a workspace

Like Steam or a game launcher. The Studio opens on Home: bot cards on one side, tools on the other. Clicking a bot opens its workspace, with tabs and a back arrow.

  • Home is a clean start page; it's obvious what bots and tools are.
  • The bot's pages get the full width.
  • Switching bots or tools means going back to Home first.

CIcon rail with two modes

Like VS Code or Outlook. A slim rail switches between Bots and Tools. The column beside it lists the bots (or the tools), and the open bot's pages are tabs.

  • Bots and tools are clearly two different worlds.
  • Switching bots is one click.
  • There are three columns, which is busier than A at small sizes.

What each page is for (the same in every option)

Bot pages work on the open bot. Tool pages work on whatever you point them at, with the open bot's assets as the default.

Overview bot

Goal: see at a glance what the bot is doing and how today is going.

  • Now, Today's round, progress, Next up
  • Run / Pause / Stop

Runs bot

Goal: find out what happened and why something failed.

  • A timeline per day
  • Failures with their screenshot

Library bot

Goal: manage everything the bot uses.

  • Images, regions, points, guides, flows
  • Rename (code updated too), retake, edit, delete
  • Test one asset → highlight it on screen

Settings bot

Goal: change how the bot plays, without code.

  • The bot's own settings, in sections

Capture tool

Goal: take a new asset, or retake one, and test it.

  • Opens on the frozen screen
  • Check = highlight it live

Recorder tool

Goal: record what you do as a flow, adding checks as you go.

Flows tool

Goal: edit a recorded or written flow, step by step.

Home / Studio settings app

Goal: add bots, choose the theme and keys, and set how the Studio behaves (tray, hiding on Run).
