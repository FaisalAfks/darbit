The capture tool, highlight, the setup guide, the recorder, the run panel and the hub, built from the same tokens and components. Themes switch everything at once. The image (cyan) is linked to an existing region (violet, named), so the readout says whether it's inside. The click point (green) starts at the centre and was dragged right: +20, 0. Every kind shows where and how big it is, and clicking a readout lets you type exact numbers. The snap guide (glow) shows which line the left edge snapped to, and the magnifier draws the box edge too. Kinds switch with the segmented control or Tab; Shift+drag always draws a region, Ctrl+click sets the point. The guide card shows the author's text (white) and the bot's text (pink chip) separately. Hover the toolbar buttons to see their keys.
