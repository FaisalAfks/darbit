import darbit as d

@d.flow
def slime():                       # d.wait("Dim.Game.Left", 30)
    d.wait("Dim.Game.Left", timeout=30)
    d.hold("w"); d.sleep(0.5); d.press("q")

    while not d.exists("Dim.Game.Leave"):
        spam_skills(times=5)
        if d.exists("Dim.Boss.Bar"):
            dodge()
        if state.sr_done > 100:          # a Code step
            d.log("almost done this week")
    d.click("Dim.Game.Leave")

Export writes plain darbit code, one statement per step. Python reads back as a flow with no decompiler: inside @d.flow, Python's own ast parser maps known statements to steps, and anything else becomes a Code step, kept word for word.
