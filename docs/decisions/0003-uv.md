# 0003 uv for environments, locking and installing

Accepted, 2026-10-25.

## Context

Environments were made with `python -m venv` and `pip install -e`, with no lock files. Nothing stopped a dependency update from changing a running bot.

## Decision

- [uv](https://docs.astral.sh/uv/) manages Python, environments and dependencies in every repo.
- `uv.lock` is committed. `uv sync` reproduces the environment exactly.
- The repo root is a uv workspace (ADR 0002).
- `uv run <command>` runs tools in the project environment.
- Later, the Studio installs as an app with `uv tool install "darbit[app]"`.

## Consequences

- uv must be installed once (`winget install astral-sh.uv`).
- `pip install -e .` still works for anyone without uv.
