# T25 Docs site, installer, API freeze

**Goal:** darbit 1.0: a stable public API, a docs site a new user can learn from alone, and a Windows installer.

**Issues:** #57, #58, #59. **Milestone:** v1.0.

## Outline

1. **API freeze:** list the public names (`darbit.__all__`), mark anything to drop as deprecated one minor version before, write `docs/api.md` from docstrings.
2. **Docs site:** MkDocs Material from `docs/`: getting started (install, first script, capture, highlight), the API, each tool, the project format, guides (`guide.toml`), run files, writing a bot. Published with GitHub Pages from `main`.
3. **Installer:** a per-user installer (Inno Setup or MSIX) that bundles Python (embeddable), darbit with the `ui` extra and the built UI, adds `darbit` to PATH and a Start menu entry for the hub. Updates through the hub.
4. **Benchmark baseline** from T21 stored with the release.

## Done when

Someone new installs darbit from the installer and makes a working first bot by following the site.
