# Changelog

## Unreleased

- Targets: images, locations, or both, loaded by name from the image folders
- Finding and waiting: `exists`, `wait`, `vanish`, `find_all`, `check`
- Mouse: `click`, `double_click`, `right_click`, `hover`, `drag`, `scroll`, with a gliding mouse
- Keyboard: `press`, `hold`, `release`, `write`, by key position
- Apps: `apps.open`, `apps.close`, `apps.running`, `apps.focus`, `apps.window`
- Settings, stop hotkey (Ctrl+Alt+Q), `sleep`, keeping the PC awake, releasing keys on exit
- Log file per day and a screenshot when a long wait runs out
